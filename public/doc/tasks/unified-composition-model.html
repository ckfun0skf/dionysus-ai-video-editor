DYS-014 — Unified Composition Model

In progress · 76% · Updated 2026-10-20

Goal

One Composition document contract and one Editor for the Project Master Timeline and nested Clip Asset Versions. Save-as-Clip must preserve editable structure.

Implemented transition slices

  • Canonical typed Composition, Track, Placement and source-reference contracts in src/compositionModel.ts.
  • Non-mutating schema-1.0 projection for root timeline and Clip Asset Versions in src/compositionMigration.ts.
  • Regression tests cover track/placement order, source ranges, linked audio, pinned Shot/Clip versions, nested layers, duplicate Storyboard placements, missing-source warnings, deterministic output and source immutability.
  • Follow-up #54 patch makes ordinary clip drop/resize account for Master Shots and applies cross-model resize trims atomically. Master Shot drag identity survives protected dragover; Master and nested Clip Timeline Add layer menus offer only Video, Audio and Text; nested Image/Code/Clip choices are in a separate Add content menu. Shared editor data/operations remain outstanding.
  • Nested Clip Timelines render Video/Audio/Text track rows with multiple placements per track. Add layer creates a track; Add content creates a placement. Compatible track moves are covered by pure tests.
  • Project import/export uses a versioned 2.0 compatibility envelope preserving the schema-1.0 payload and storing the canonical Composition projection. This is not canonical-only persistence.
  • Shared Master Shot/ordinary move, drop and resize operations are in src/projectTimelinePlacement.ts. Structural Project-to-Clip snapshots and full root/nested state unification remain outstanding.
  • CI #39218891285 passed tests, TypeScript and Vite production build on consolidated head 2763f3b0a98823ef5d59a3760486adb302cc31d2.

Timeline-first workspace direction

The Editor workspace owns Media/Audio/Text/Effects/Transitions browsing, Preview/Canvas and the lower multitrack Timeline. Mobile bottom controls are contextual to selection; product-module navigation is separate. Follow Workspace Architecture and Rebuild Plan. PR #89 is an unmerged Draft; exact-head TypeScript/build failed at the last check.

Target contract

  • Project root is a Composition; Clip Asset is a reusable, versioned Composition.
  • Shot is narrative/production identity with concrete generated video alternatives, not a nested timeline.
  • Placements pin concrete versions and share editing mechanics.
  • Add Track is Video, Audio and Text at every composition depth.
  • Save-as-Clip preserves tracks, placements, source ranges, nested refs and pinned versions.
  • Migration of the current schema is deterministic and non-destructive.

Acceptance

  • Root and nested compositions share schema and editing mechanics.
  • Snapshots can be placed and expanded without mutating source Projects.
  • Migration, JSON round-trip, nested render and interaction tests pass.
