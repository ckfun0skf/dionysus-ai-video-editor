# DYS-005 — Precise Timeline editing and Version management

**Status:** Planned  
**Progress estimate:** 0%  
**Last updated:** 2026-10-17

## Summary
Upgrade the Timeline visualization to a practical editor with precise timing, tracks, clip slots, multiple versions, and nested composition editing.

## Scope
- [ ] Support accurate clip timing, source trim, overlapping layers, and track operations.
- [ ] Allow multiple Clip Slots per Shot and reusable assets across Shots.
- [ ] Manage multiple Versions per Slot; regeneration defaults to creating a new Version.
- [ ] Support internal Version timelines and nested compositions with depth/cycle protection.
- [ ] Define explicit fixed-duration, auto-extend, and ripple operations.

## Implemented / verified
- None recorded yet.

## Remaining work
- Current Timeline is visualization-only and is not a frame-accurate drag-and-drop editor.
