Dionysus · M3 Timeline model & Version workflow

Reusable Clip Assets and nested composition timeline

A reusable Clip is a versioned composition Asset that can be edited independently and nested inside another Clip or Master Timeline placement.

DYS-013Implementation complete for this sliceLast updated · 2026-10-18

Goal

Build a reusable, cycle-safe Clip Asset graph with independent Versions, an in-workspace nested timeline, explicit version pinning, and deterministic project validation.

Delivered behavior

  • Create empty Clip Assets with canvas dimensions and a positive duration.
  • Open a Clip Version in a separate Timeline tab; add and edit video, image, audio, text, Code/procedural, and nested Clip modules.
  • Duplicate a Version while retaining the original and generating new module IDs.
  • Pin nested Clip Version IDs; prevent direct and indirect composition cycles.
  • Validate asset, version, layer, and referenced-image IDs before loading or importing project data.
  • Expand placed Clip Assets into timed layers and render nested composition frames recursively where supported.
  • Expose only explicitly selected image references to sandboxed Code previews.

Validation

Implementation commit 9a2f7b0 passed GitHub Actions run #39153686513: 14 test files, 118 tests, and a successful Vite production build. This predates the task-tracking/readme-only batch, so verify the latest PR head again before merging. Browser smoke tests were not run.

Known scope boundaries

  • WebM export is experimental and browser-capability dependent; this is not a frame-accurate professional NLE or MP4 exporter.
  • Media decode, CORS, missing source media, and browser codecs must be reported honestly.
  • Full Shot identity/Version migration and broader reference-management improvements remain separate follow-up work.
