Scope

  • Keep Master Timeline open while a selected Shot Version opens in a new timeline tab.
  • Show a thumbnail/placeholder and Version dropdown on each Master Shot, including + Add Version and Edit per Version.
  • Do not display a generic Media track; show typed video, text, audio, and procedural lanes.
  • Separate master Shot duration/placement from nested Version timing.
  • Preserve multiple Versions, nested composition depth/cycle safety, Undo/Redo, and project JSON relationships.

Implemented / verified

  • Master Timeline shows Shot blocks with a Version dropdown, + Add Version, and Edit per Version.
  • Master Timeline remains available while a Shot Version opens in an additional timeline tab.
  • Nested Version tabs show separate typed internal layer lanes, including a procedural/Three.js lane.
  • Optional Shot.masterStart stores absolute Master placement; legacy projects retain sequential fallback until edited.
  • Shot start can be edited in Inspector or moved by drag-and-drop with frame-rate snapping.
  • Master Shot duration, Clip Slot duration, and Version-internal duration no longer resize one another implicitly.
  • Composition collection uses absolute Master Shot offsets and preserves the stored Version layer order.
  • Imported images/videos and generated image outputs attempt to store compact local thumbnails; unsupported video decode leaves a placeholder.
  • Nested Video/Audio modules expose source in/out controls independent of Version/Shot timing.
  • Master clip Inspector supports frame-snapped midpoint split; video and linked audio split together, preserve contiguous source ranges, and keep fade-in/out boundaries on the appropriate segment.
  • Trim operations synchronize sourceOut with the new duration and clamp fade values to avoid invalid project state.
  • Project JSON round-trip coverage preserves Master placement, nested layer order/source ranges, linked audio, mute/mix settings, and saved thumbnail references.
  • CI run #39123087834 passed 91 tests across 10 files, TypeScript and production build; npm audit found 0 vulnerabilities.

Remaining work
