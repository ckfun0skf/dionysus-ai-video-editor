DYS-012 · M4 — Preview, compositing, and mobile editing

Responsive mobile editing

In progress · Responsive layout foundation only

Goal

Deliver a CapCut-inspired phone workflow while preserving Dionysus's multi-track project model and desktop editing. Responsive mobile web is the first target; a native app is not implied.

Implemented in current feature branch

  • Persistent bottom navigation for Storyboard, Timeline, Assets and References, with safe-area spacing.
  • Compact top bar and reduced page-heading chrome on phones.
  • Preview-first timeline layout with larger playback and insertion controls.
  • Horizontally pannable timeline surfaces and sticky track labels.

This branch is not yet merged or deployed.

Still required

  • Touch-first clip selection, drag/reorder, precise scrubbing and trimming.
  • Mobile Inspector and Version picker interactions.
  • Portrait, landscape and tablet viewport validation, including page-level overflow.
  • Exact-head CI/build and post-merge deployment evidence.

Verification policy

No automated browser smoke tests are added or run. Automated checks, deployment status and any later manual device acceptance must be reported separately.
